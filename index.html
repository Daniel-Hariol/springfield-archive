SOBRE O PROJETO

Muito além de um desenho.

Springfield Archive é um projeto acadêmico desenvolvido para explorar o universo dos Simpsons por meio de uma interface web interativa.

As informações dos personagens são obtidas diretamente de uma API pública e apresentadas dinamicamente na página utilizando JavaScript.

01
Dados reais

Informações obtidas por meio de uma API externa.

02
Interface dinâmica

Cards criados automaticamente pelo JavaScript.

03
Experiência responsiva

Layout adaptado para computadores e smartphones.
